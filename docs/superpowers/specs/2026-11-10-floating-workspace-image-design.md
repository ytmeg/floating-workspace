# 悬浮工作台图片模式设计

- 日期：2026-11-10
- 状态：用户以 `/goal 完成开发图片模式` 授权按既定图片范围继续
- 项目：悬浮工作台
- 范围：本地图片导入、替换、删除、缩放、裁剪、画笔／文字／箭头标注和导出

## 1. 目标与边界

在现有悬浮工作台中启用图片模式，保留便签、空白、网页、玻璃主题、置顶、快捷键、持久化和窗口恢复。

- 只处理用户主动选择或拖入的本地图片，不读取其他目录或屏幕内容。
- 支持 PNG 和 JPEG；其他格式显示不支持错误，不静默转换。
- 原图与编辑模型分离保存，不覆盖用户原文件。
- 不引入网络、账号、屏幕录制权限或第三方图片库。
- 网页模式已有数据和行为必须保留，图片与网页草稿使用独立字段。

## 2. 图片工作流

### 导入与替换

- 支持 `NSOpenPanel` 选择和拖入 PNG/JPEG。
- 导入时将图片复制到 Application Support `FloatingWorkspace/Images/<uuid>.<ext>`，避免原文件移动后失效。
- 替换图片会生成新文档，不删除旧原图；用户明确删除文档时才清理其本地副本。
- 单个文档文件上限 50MB，超出时显示原因。

### 显示与缩放

- 默认按窗口等比适应，保持原始宽高比。
- 缩放范围 10%–400%，以原图像素为基准，不拉伸变形。
- 显示区域不足时保持居中，窗口 resize 后重新计算可视区域。

### 裁剪

- 进入裁剪模式后显示可拖动、可缩放的裁剪框。
- 裁剪框使用归一化坐标 `x/y/width/height ∈ 0...1`，始终位于原图范围内并保持原图宽高比。
- 裁剪只改变导出结果和预览，不修改原图。
- 支持重置为完整图片。

### 标注

- 画笔：颜色、线宽和归一化点序列。
- 文字：内容、颜色、字号和归一化位置。
- 箭头：颜色、线宽、归一化起点和终点。
- 支持撤销最后一次标注和清空全部标注。
- 坐标均相对于原图，缩放或裁剪时正确映射。

### 导出

- 导出为 PNG，包含当前裁剪和所有标注。
- 输出尺寸为裁剪后原图像素尺寸，不额外放大。
- 合成使用 CoreGraphics，保持颜色空间、透明通道和文字可读性。
- 导出路径由用户选择，使用临时文件加原子替换；失败不覆盖已有文件。

## 3. 数据模型与迁移

新增 `ImageDocument`：

- `id`：UUID 字符串。
- `originalRelativePath`：Application Support 内相对路径，禁止目录穿越。
- `displayScale`：0.1–4.0。
- `cropRect`：归一化 x/y/width/height。
- `annotations`：画笔、文字、箭头数组。
- `updatedAt`：最后编辑时间。

`ImageAnnotation` 使用关联值枚举：

- `pencil(points, color, width)`。
- `text(content, color, fontSize, position)`。
- `arrow(start, end, color, width)`。

`WorkspaceContent` 升级为 `schemaVersion = 3`，增加可选 `imageDocument`。读取 v1/v2 时保留便签、空白、网页草稿、置顶和窗口状态，补空图片文档并迁移为 v3；保存只接受 v3。迁移备份复用现有精确字节、去重和不覆盖策略。

## 4. 组件设计

### ImageDocumentStore

负责导入复制、相对路径校验、删除、模型更新和 schema v1/v2→v3 迁移，复用 `ContentStore` 的防抖、原子保存和退出流程。

### ImageCanvasView

负责原图、裁剪框和标注的 CoreGraphics 绘制，以及缩放、裁剪框和画笔／箭头事件映射。视图不直接读写文件。

### ImageEditController

负责工具栏、缩放、裁剪、标注工具、撤销／清空和导出。每个操作先更新模型，再触发现有保存流程。

### ImageExporter

负责按裁剪像素尺寸合成 PNG，独立可测试，不依赖 `NSView` 截图或屏幕录制。

## 5. 错误处理

- **格式不支持/解码失败**：保留当前文档并显示原因，不创建空文档。
- **文件过大**：拒绝导入并显示 50MB 上限。
- **路径非法/目录穿越**：拒绝读取或删除，不触碰外部文件。
- **保存失败**：沿用 dirty、失败提示和退出重试/明确放弃流程。
- **导出失败**：不覆盖目标文件并保留当前编辑。
- **空标注/空文字**：忽略，不创建无效模型。

## 6. 验证策略

### 自动化测试

- 归一化裁剪框、缩放范围和标注坐标映射。
- 导入复制、替换、删除和路径安全。
- v1/v2→v3 迁移及网页草稿保留。
- 画笔、文字、箭头模型校验和撤销/清空。
- CoreGraphics 裁剪像素尺寸、合成颜色和透明通道。
- 导出失败不覆盖目标，现有全部测试不回归。

### 真机验收

1. 导入 PNG/JPEG，原文件移动后图片仍可用。
2. 缩放、窗口 resize 和裁剪框保持比例及坐标正确。
3. 画笔、文字、箭头撤销/清空和重启恢复正确。
4. 导出 PNG 的尺寸、裁剪和标注与预览一致，原文件未被修改。
5. 替换/删除、非法格式、超大文件、保存失败和导出失败均有可见提示。
6. 浅色/深色/减少透明度下图片和工具栏可读，原八组功能验收不回归。

## 7. 完成标准

只有模型/迁移/导出测试、真实图片编辑、持久化、错误路径、主题检查和原八组功能验收全部通过，才可声明图片模式完成。网络图片、视频、屏幕录制和远程图片编辑不纳入本次完成声明。
